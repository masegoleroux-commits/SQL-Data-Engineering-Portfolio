# Data dictionary

| File | Grain | Notes |
|---|---|---|
| calendar.csv | one round | DD/MM/YYYY dates; Imola listed with no date |
| race_results.csv | one driver in one Grand Prix | Time/Retired mixes times, gaps, laps and statuses |
| sprint_results.csv | one driver in one sprint | no fastest-lap column |
| qualifying_results.csv | one driver in one qualifying | Q1-Q3 as m:ss.fff, blank if eliminated |
| drivers.csv | one driver | career figures, not used for 2023 points |
| teams.csv | one constructor | Haas listed as 'Haas F1 Team' |
