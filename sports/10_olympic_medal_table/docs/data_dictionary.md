# Data dictionary

| Column | Notes |
|---|---|
| ID | athlete ID; with Games and Event, the grain of every entry |
| Team | country or crew name (`United States-2`); NOC is the reliable key |
| NOC | three-letter National Olympic Committee code |
| Games | e.g. `2016 Summer` |
| Medal | Gold / Silver / Bronze / NA |
| Height, Weight, Age | NA when unknown |
